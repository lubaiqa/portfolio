# Lubaiqa Asif — Portfolio

A full-stack developer portfolio built with the MERN stack, showcasing my projects, skills, and a working contact form backed by a real database.

## Tech Stack

**Frontend:** React (Vite), Tailwind CSS, React Icons
**Backend:** Node.js, Express.js
**Database:** MongoDB (Atlas)

## Features

- Responsive, animated UI
- Project showcase with GitHub and live demo links
- Contact form that saves messages to MongoDB via a REST API
